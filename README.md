# 🏛️ UniPlan SaaS Ecosystem

**موزع الجداول الدراسية وحراسة الامتحانات الذكي (الإصدار السحابي المتعدد الأقسام)**

نظام سحابي (SaaS) متكامل ومبني لخدمة المؤسسات الأكاديمية والجامعات. يوفر المنصة بيئة معزولة لكل قسم أو كلية (Tenant Architecture)، مع لوحة تحكم مركزية للإدارة العليا. يعتمد النظام على خوارزميات ذكية (Metaheuristics) لتوليد الجداول الدراسية وتوزيع حراسات الامتحانات بشكل آلي وعادل.

---

## ✨ ميزات النظام الرئيسية

### 1. لوحة الإدارة المركزية (Super Admin)
* إدارة الأقسام والكليات (Tenants) ببيئات بيانات معزولة تماماً.
* التحكم في صلاحيات الوصول للأنظمة (تفعيل/تعطيل نظام التدريس أو الامتحانات لكل قسم بضغطة زر).
* إحصائيات شاملة ومراقبة للنظام.

### 2. 🗓️ نظام الجداول الدراسية (Teaching Module)
* إدخال وإدارة الأساتذة، المستويات، القاعات، والمواد.
* التمييز بين أنواع الدروس (محاضرات، أعمال موجهة، أعمال تطبيقية).
* خوارزميات جدولة ذكية تعمل في الخلفية (Background Tasks).
* واجهة "بوابة الأستاذ" لإدخال الرغبات والأيام المفضلة.

### 3. 🎓 نظام حراسة الامتحانات (Exams Module)
* تزامن سحري (Sync) لسحب الأساتذة والمواد والإسنادات مباشرة من نظام التدريس.
* إدارة فترات الامتحانات (أساسية/احتياطية) وبناء هيكل الأيام.
* ضبط قيود دقيقة: الإعفاءات، التنافر بين الأساتذة، الحد الأقصى للحراسة، ومراعاة فترات التدريس.
* التوزيع العادل للحراسات وتوليد الجداول وتصديرها.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Backend:** Python, Flask, SQLAlchemy (ORM)
* **Background Processing:** Celery
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Architecture:** Multi-tenant SaaS (Schema/Tenant-ID isolation)
